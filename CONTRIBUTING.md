# Как помочь проекту

Баги и идеи — в [issues](https://github.com/saxxumm/PrixumLauncher/issues), исправления и новые функции —
в pull request'ах.

## Pull request

1. Собери лаунчер по инструкции из [README](README.md#сборка-из-исходников) и проверь изменения вживую.
2. Отформатируй код: `clang-format -i <файлы>` (настройки лежат в `.clang-format`).
3. Прогони тесты: `ctest --test-dir build`.
4. В описании PR расскажи, что изменилось и зачем. Для изменений интерфейса приложи скриншоты.

Сборка идёт с `-Werror`, поэтому любое предупреждение компилятора остановит CI.

## Темы и переводы

Новые встроенные темы лежат в `launcher/resources/nova/presets/`, базовые стили — в
`launcher/resources/nova/style.qss`. Русские строки нового интерфейса — в `launcher/resources/nova/i18n/ru.po`.
Формат тем и все токены описаны в [PRIXUM.md](PRIXUM.md).

## Лицензия
